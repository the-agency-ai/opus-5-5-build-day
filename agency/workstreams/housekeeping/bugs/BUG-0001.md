# BUG-0001: Write(**) permission allow rules in settings.json rejected at startup — "use Edit(**) instead"

**Status:** Open
**Reported:** 2026-10-13
**Assigned To:** captain
**Workstream:** housekeeping

## Description

On `claude` startup, Claude Code emits warnings that the `Write(...)` permission allow rules in `.claude/settings.json` are not honored by file permission checks, and advises replacing them with `Edit(...)` rules:

```
Permission allow rule (.claude/settings.json): Write(**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(**) instead (Edit rules cover all file-editing tools).
Permission allow rule (.claude/settings.json): Write(.claude/skills/**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(.claude/skills/**) instead (Edit rules cover all file-editing tools).
Permission allow rule (.claude/settings.json): Write(/tmp/**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(/tmp/**) instead (Edit rules cover all file-editing tools).
Permission allow rule (.claude/settings.json): Write(/var/folders/**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(/var/folders/**) instead (Edit rules cover all file-editing tools).
```

The `.claude/settings.json` permission allowlist uses `Write(...)` glob rules that no longer match file permission checks; those checks only recognize `Edit(path)` rules (which cover all file-editing tools, including Write). The `Write(...)` entries should be migrated to `Edit(...)`.

## Steps to Reproduce

1. Have a `.claude/settings.json` with permission allow rules of the form `Write(**)`, `Write(.claude/skills/**)`, `Write(/tmp/**)`, `Write(/var/folders/**)`.
2. Launch `claude` in this repo.
3. Observe the four warning lines on startup.

## Expected Behavior

Either the `Write(...)` allow rules are honored, or (per the warning's own guidance) the settings are migrated to `Edit(...)` rules so the allowlist takes effect and the startup warnings stop.

## Suggested Fix

In `.claude/settings.json`, replace each `Write(<glob>)` permission allow rule with `Edit(<glob>)`:
- `Write(**)` → `Edit(**)`
- `Write(.claude/skills/**)` → `Edit(.claude/skills/**)`
- `Write(/tmp/**)` → `Edit(/tmp/**)`
- `Write(/var/folders/**)` → `Edit(/var/folders/**)`
